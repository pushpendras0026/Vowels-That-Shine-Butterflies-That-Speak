The equations

ci = Ai − Ai+1Ai + Ai+1  =  ni − ni+1ni + ni+1

Pressure-wave reflection at a tube junction = E-field Fresnel reflection at normal incidence, with n ∝ A.

nidi = dopt = c2 Δν = 199.86 nm

Goupillaud condition: every layer has the same optical thickness, just as every tube section has the same delay (ℓ = L/N, one sample per round trip).

P(ω) = Πi (1 − ci2)|D(ejω)|2

Shared power transfer. Tube: ω = 2π f / FS. Film: ω = 2δ, δ = 2π (n d) ν / c.

[F, G] ← [F + ci z−1G,  ciF + z−1G]

Step-up (add one section / layer), starting from [1, c0]; D(z) = F after N steps. With c0 = −1 (closed glottis) this is Levinson’s step-up with km = −cm.

ci = Gi[0],  Fi−1 = Fi − ciGi1 − ci2

Step-down = layer peeling: the first echo reveals the next interface; divide it out and repeat (LPC step-down in the closed-glottis case).

f(ν) = FS · frac(ν / Δν)

Exact phase identity ω = 2δ (mod 2π).

Why any common optical thickness works

exact
δ = 2π dopt νc,  dopt = nidi (same for every layer)

Each layer delays the wave by the same phase δ — the optical analogue of one tube section = half a sample of delay each way.

ω = 2δ = 4π dopt νc  ≡  2π fFS  (mod 2π)

The ci depend only on the indices, so T(ν) = P(ω(ν)) whatever dopt is: the thickness only rescales the frequency axis.

f = FS · frac(ν / Δν),  Δν = c2 dopt

Brief: dopt = 428.27 nm ⇒ Δν = 350 THz; the visible band is one full period, so 0–8 kHz appears twice (mirrored at 525 and 700 THz).

|f| = FS (1 − ν / 750 THz)  for 400 ≤ ν ≤ 750 THz

Full-band: dopt = 199.86 nm (half-wave at 400 nm) ⇒ Δν = 750 THz, f = 0 sits at 750 THz and 400–750 THz shows 7.47 → 0 kHz exactly once (no mirror image).
